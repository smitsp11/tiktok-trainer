# Placeholder Assets for TikTok Trainer

This directory contains placeholder assets for the TikTok Trainer app.

## Required Assets

### App Icons
- `icon.png` - Main app icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon (32x32)

### Splash Screen
- `splash.png` - App splash screen (1242x2436)

### Notification
- `notification-icon.png` - Notification icon (96x96)

## Asset Guidelines

### App Icon
- Size: 1024x1024 pixels
- Format: PNG
- Style: Modern, TikTok-inspired design
- Colors: Primary #FF0050, Secondary #FF4081
- Should represent camera/recording theme

### Splash Screen
- Size: 1242x2436 pixels (iPhone X dimensions)
- Format: PNG
- Background: White or gradient
- Logo: Centered TikTok Trainer logo
- Text: "TikTok Trainer" or app name

### Notification Icon
- Size: 96x96 pixels
- Format: PNG
- Style: Simple, monochrome
- Theme: Camera or recording related

## Creating Assets

You can create these assets using:
- Design tools: Figma, Sketch, Adobe XD
- Image editors: Photoshop, GIMP
- Online tools: Canva, LogoMaker
- AI tools: DALL-E, Midjourney

## Temporary Solution

For development purposes, you can:
1. Use Expo's default assets temporarily
2. Create simple colored squares as placeholders
3. Use online icon generators for quick prototypes

## Asset Optimization

When creating final assets:
- Optimize file sizes for mobile
- Use appropriate formats (PNG for transparency, JPEG for photos)
- Test on different screen sizes
- Ensure accessibility compliance
- Follow platform-specific guidelines (iOS HIG, Material Design)
