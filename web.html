🚀 How to Run TikTok Trainer on Web

Since webpack is having compatibility issues, here are the working commands:

  1. Start Metro bundler:
    npx expo start
  2. Open web version:
    Press w in the terminal, or visit:
    http://localhost:8081
  3. Alternative - Mobile:
    npm run ios or npm run android

📱 Features Available

  • ✅ Streak tracking and progress visualization
  • ✅ Micro-prompt cards for inspiration
  • ✅ Achievement system
  • ✅ Settings and preferences
  • ⚠️ Camera features (limited on web)

🔧 Troubleshooting

If you encounter issues:

  1. Make sure you're using Node.js 20+: node --version
  2. Clear cache: npm cache clean --force
  3. Reinstall dependencies: rm -rf node_modules && npm install
